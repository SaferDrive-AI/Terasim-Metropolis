# Examples

All examples use synthetic data only.

| Directory | What it shows |
| --- | --- |
| `corridor_demo/` | A synthetic three-signal arterial (map, signal programs, turning-movement counts, timing sheets, ten-minute snapshots) and three walkthroughs of the HTTP API: on-demand, scheduled and incident-triggered optimization |
| `acceptance/` | The end-to-end acceptance check: brings up the service, MCP server and TMC collector on the demo corridor, exercises both operating modes and checks the KPI and NEMA outputs |
| `plugins/` | A third-party traffic-operation plug-in built against the Plugin SDK, installable as its own package |
